## Investigation of 311 Service Requests from Louisville, Kentucky, US in 2025
Seeks to determine which services are most requested, and by whom, for the *potential* purpose of city budget expediture redirection.

### Instructions:
Jupyter notebook may be viewed directly on GitHub, or the repository may be cloned for further examination of the data.
Included files:
- *Lou311_EDA.ipynb* : Jupyter notebook detailing exploratory data analysis of data sourced from https://data.louisvilleky.gov/datasets/LOJIC::louisville-metro-ky-metro-311-service-request-2025/about
- *metro_311_2025.csv* : Copy of original CSV file retrieved from https://data.louisvilleky.gov/datasets/LOJIC::louisville-metro-ky-metro-311-service-request-2025/about
- *README.md* : This file.
- *LICENSE* : Copy of GPL 3 license text.
- *requirements.txt* : Python-generated list of requirements
- *./archived* : directory containing an older copy of the Jupyter notebook, including more detailed descriptions of data cleaning process (recorded in real-time as data was cleaned and wrangled)
